# Manuscript Data and Code Availability Statement

## Recommended wording for the current manuscript

The IRMSD reproducibility package is archived on Zenodo as release v0.1.0 (version-specific DOI: https://doi.org/10.5281/zenodo.24155679). The Concept DOI for the software project and all its versions is https://doi.org/10.5281/zenodo.24155678. The source repository is available at https://github.com/alimkiq-design/IRMSD-Reproducibility-Package.

The package includes the prototype implementation and regression tests, sprint-pilot analysis scripts, documentation, and a synthetic sprint telemetry dataset used solely to demonstrate the analytical pipeline. The synthetic data do not represent observations from real software development teams. An expert-adjudicated risk-classification benchmark, comparative model evaluation, and longitudinal field-study data are not included in this release.

## Citation guidance

Use the **version-specific DOI** (10.5281/zenodo.24155679) in the manuscript because it identifies the exact v0.1.0 package snapshot. Use the **Concept DOI** (10.5281/zenodo.24155678) in repository badges or references to the evolving software project as a whole.

## Important

Do not describe the synthetic sprint analysis as field validation, industrial evaluation, or empirical evidence of effectiveness. Update this statement if a future archived release adds genuine expert-adjudicated benchmark data or real-team observations.
